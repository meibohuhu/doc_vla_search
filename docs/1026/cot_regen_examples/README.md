2026-10-27。说明：[cot_regen_navtrain.md](../cot_regen_navtrain.md)。代码：`/home/mh2803/vla/Impromptu-VLA/data_qa_generate/data_engine/datasets/navsim/build_navsim_cot.py`。

都是 navtrain 的帧，能挑到和 166k 重合的 token 就挑重合的，标题里同时给出新生成的（NEW）和 166k 老版的（OLD）句子。

每张图：左边 t = 0 前视图，右边 BEV（自车坐标系，上为前）：
- 绿色：自车；黑点：专家 GT（每 0.5 s）；
- 蓝色带：自车路径带（GT 路径沿末端航向延长到 45 m，深色 ±1.5 m，浅色 ±2.0 m），切入和停车标志都在它上面判；
- 灰色虚线框：前车走廊（正前 5–40 m、横向 < 4 m）；橙色点线：VRU 只看 20 m 以内；
- 紫色：车；橙色：行人；青色：骑行者。黑框是句子里提到的那个（LEAD = 前车，CUT = 切入），线和点是它未来 3 s 的真实位置；
- 红框：STOP_SIGN 停车线（只画这一类）。

## 看图过程中修掉的两个问题

1. **自车快停下时路径带歪出去**：原来按 GT 最后一段位移定延长方向，快停下时最后一段只有几厘米，方向是噪声，路径带斜着出去，停车线就压不到。改用 GT 末点自带的航向。
2. **斜着的大停车线判不到**：原来看停车线的中心点离路径多远，斜的大多边形中心会偏到车道外 3 m。改成看多边形和路径线是否相交。

改完以后 navtrain 的停车标志从 0.6% 变成 1.6%（老版 1.0%），新多出来的抽查过都是对的（`j_*`）。

## 照搬下来的老毛病

- 前车走廊横向 < 4 m，比一条车道宽，旁边车道的车也会被写成 "in my lane"（`g_gap_big2` 的校车）。为了和 166k / 老 103k 保持一致没改：跟车占 29.5%，改它等于改大部分数据。
- 停着的自车在路口等红灯时，理由只能是前车 / 切入 / 停车标志，不会是红灯。
